Technical Specifications

Frontend Architecture

Built with Vanilla JavaScript, HTML5, and CSS3. Responsive design using Flexbox and Grid. Communicates with backend via Fetch API.

Backend Engine

Powered by Python FastAPI for high-performance asynchronous API handling. Background tasks manage heavy video processing without blocking.

Video Processing

FFmpeg integration for professional-grade video manipulation, including frame-accurate cutting, stream concatenation, and subtitle burn-in filters.

Automation Algorithm

Scene selection simulator parses SRT subtitle timings to identify key dialogue moments, ensuring the recap captures the essence of the movie.
